Core Engineering Contributions

  • Native Swift glTF/GLB Serialization Engine (Phase 1): Constructed a zero-dependency binary `.glb` packer in native Swift that traverses SceneKit's `SCNScene` graph. Unlike standard USDZ converters that flatten hierarchies or cause scale drift, our engine maintains 1:1 metric scale mapping and enforces semantic node isolation (`_`, e.g., `Wall_1`, `Sofa_1`) so individual furniture items can be grasped and moved inside Meta Quest VR.
  • Generative 3D Asset Replacement via ShilpAI (Phase 2): Built the "Magic Generate" client-server workflow connecting iOS to a Pegasus GPU server. Converts text descriptions or single photos into rich 3D geometries via TRELLIS and synthesizes physically-based rendering (PBR) roughness, metallic, and normal maps via Hunyuan3D-2.1.
  • Dynamic Bounding-Box Fitting & Direct-Manipulation Gestures: Dynamically clears primitive bounding boxes, wraps USDZ models under a `"CustomModelRoot"` node, and computes uniform matrix scale factors to fit custom furniture snugly into RoomPlan's measured real-world dimensions. Integrated `UIPinchGestureRecognizer` for continuous scaling and `UIPanGestureRecognizer` for dragging models across the floor.
  • On-Device Instant Vision Matching (Phase 3): Solved the 30–120s cloud generation wait time by implementing zero-latency on-device matching using Apple's Vision framework (`VNGenerateImageFeaturePrintRequest`). During scanning, an Algorithm R reservoir sampling cache (`ScanFrameCache.swift`) captures 200 memory-safe camera frames. At scan end, `ObjectPhotoCropper.swift` back-projects 3D object centroids to crop the most centrally framed photo and matches it against previously generated local assets.

💡 Closing the Visual Quality Gap (Matching Polycam)

To eliminate the flat gray appearance of raw RoomPlan output, we introduced a centralized lighting and shader system (`RoomStyleHelper.swift`). It deploys an ambient fill light with a directional key light casting soft shadows (`shadowRadius = 8.0`), generates procedural Honey Oak wood parquet floor textures via `UIGraphicsImageRenderer` without asset bundle bloat, and assigns distinct physical PBR shaders (fabric sofas, mahogany tables, matte cabinets, steel appliances) baked directly into the exported `.glb` stream for Unity parity.
