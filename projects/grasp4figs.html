GRASP4Figs: OCR-Augmented Reward-Conditioned Captioning for Scientific Figures

An OCR-injected and reinforcement learning-steered pipeline for paragraph-length scientific plot descriptions.

Accepted at: 17th Indian Conference on Computer Vision, Graphics and Image Processing (ICVGIP 2026)
Authors: Nadgir et al.
Focus: Multimodal Figure Understanding, Vision-Language Models, Reinforcement Learning (RLHF), Qwen2.5-VL
Links: ↓ PDF Paper

Abstract: Generating faithful, informative textual descriptions of scientific figures is a formidable challenge in multimodal document understanding. While reward-conditioned frameworks exist, they process figures without access to embedded textual content (axis labels, legend entries) and remain restricted to short captions. To address this, we propose GRASP4Figs to inject OCR-derived context directly into the captioning pipeline and extend generation to paragraph-length analytical descriptions.

Figure 1: GRASP4Figs Case 1 Core Architecture. Three input streams—visual embeddings from ViT-Base, OCR context tokens prepended to the prompt, and a UDRL composite reward control token—are fused and processed by a BLIP-Base decoder.

Core Methodology

Case 1: OCR-Augmented UDRL-HF (Short Captioning)

We augment a BLIP vision-language model by prepending tokenized in-figure OCR text (axis labels, numbers, and legends) to the training prompt. To optimize for helpfulness and informative length, we combine human feedback helpfulness scores with a detail-aware length reward in an offline Upside-Down Reinforcement Learning (UDRL-HF) framework. This allows the model to capture domain-specific vocabulary and axis quantities directly.

💡 Mention-Paragraph-Induced Grounding Collapse (MPGC)

A key finding of this work is MPGC (Case 2): fine-tuning large models (like Qwen2.5-VL-7B) on mention-paragraphs causes them to hallucinate paper-specific experimental methodologies not visible in the figure itself. We resolve this by bypassing fine-tuning completely, utilizing frozen models guided by a structured zero-shot prompt with strict observation constraints.

Case 2: Zero-Shot Structured Prompting (Paragraph-Length)

For long-form description, we guide the frozen Qwen2.5-VL-7B-Instruct using structured prompts that decompose captioning into: (1) figure type identification, (2) axis and variable descriptions, (3) primary trend characterization, and (4) conclusions, under a strict grounding constraint ("Only describe what you can directly observe").

Results and Web Application

  • Quantitative Gains: GRASP4Figs achieves a BLEU-4 of 0.0373 (+96.3% over FigCaps-HF baseline) and a ROUGE-L Recall of 0.3782 on 176-word paragraphs.
  • Interactive App: Built an end-to-end web application with React + Vite frontend and FastAPI backend. It extracts figures from PDFs (using PyMuPDF) and streams Qwen2.5-VL descriptions in real-time, backed by an interactive question-answering chatbot.
